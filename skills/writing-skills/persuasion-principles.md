# Persuasion Principles for Skill Design

**Load this reference when:** hardening a discipline skill against rationalization (authority, commitment, etc.).

LLMs respond to persuasion patterns. Use them so critical practices hold under pressure — not to manipulate users.

## Principles (short)

| Principle | Skill use |
|-----------|-----------|
| Authority | Imperatives for non-negotiables ("YOU MUST", "No exceptions") |
| Commitment | Announce skill use; explicit A/B/C choices; checklist completion |
| Scarcity | "Do this before X costs more later" only when true |
| Social proof | "Agents that skip this reintroduce bugs" with real pattern |
| Unity | "We ship only with evidence" shared standard |
| Reciprocity / liking | Prefer rare; recipes beat flattery |

## Discipline skills

Pair iron laws with rationalization tables and red-flag lists. Close named loopholes from baseline pressure tests.

## Shape problems

For wrong-shaped output, prefer positive recipes over prohibition lists. See SKILL.md "Prune" / form-matching notes.
